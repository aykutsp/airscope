# code of conduct

Short version: **be the kind of person you'd want to work with**.

- Treat other contributors with respect, even when you disagree.
  Disagree on the idea, not the person.
- Assume good faith. If you can read a comment two ways, pick the
  charitable reading.
- No harassment, discrimination, or personal attacks. That includes
  sexualized content, doxxing, and dogpiling.
- Keep security tooling conversations on the side of *visibility and
  analysis*. airscope does not ship cracking code on purpose — the
  issue tracker follows the same principle.

## reporting

If someone's behaviour in this project's space (issues, pull
requests, discussions, or any related channels) is making you
uncomfortable, contact the maintainer:

**aykut.supurtulu@gmail.com**

Reports are treated confidentially. The maintainer can and will
warn, ban, or remove contributions at their discretion if the
code of conduct is violated.

## scope

This document applies inside the repository, in PR reviews, in
issues, and in any ad-hoc chat group dedicated to the project.
